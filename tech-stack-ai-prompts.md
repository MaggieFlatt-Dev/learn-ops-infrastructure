# Tech Stack AI Prompts

## 1. Run Questions

### 1a. Config Files
Find all config and environment files in the repo and fill in a markdown table with columns: Config File, Location, Config Value, What It's For, How It's Used. Include at least 3 values per file


### 1b. How to Start It
Find the Makefile at the root of this repo and list the targets relevant for starting the system. Explain what each target does and how they differ.


### 1c. Where to Access It
Find each service's port and URL and put them in a markdown table with columns: Service, Port, URL. Use config files and docker-compose files in this repo.


### 1d. Service Dependencies
Map service dependencies in a markdown table with columns: Service, Depends On, Why. In the Why section explain the reason, not just the names of the dependency.


### 1e. Main Entry Points
Find, for each service, the startup file and the routes/URL config file. Put it in a markdown table with columns: Service, Startup File, Routes/URL Config File. These are two different files per service.


## 2. Services
Create a markdown table with columns: Service Name, Tech Stack (including version), and Purpose. One row per service.


## 3. System Overview
Write a system overview in 3 paragraphs: 1. Describe what kind of application this is and what problem it solves. 2. Describe its main features from a user's perspective. 3. Describe who uses it and whether roles interact with it differently.
